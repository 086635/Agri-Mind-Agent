# 智慧农业 AI 网关系统 - 启动指南


## 🔧 环境配置

### 1. 创建 .env 文件

在 `core/` 目录下创建 `.env` 文件：

```env
# 运行环境
ENV=dev
DEBUG=true

# 数据库配置 (请替换为您的实际配置)
DATABASE_URL=postgresql://postgres:YOUR_DB_PASSWORD@localhost:5432/agri_ai
ASYNC_DATABASE_URL=postgresql+asyncpg://postgres:YOUR_DB_PASSWORD@localhost:5432/agri_ai

# API Keys (请替换为您的实际 API Key)
QWEN_API_KEY=YOUR_QWEN_API_KEY_HERE
ANYTHING_LLM_API_KEY=YOUR_ANYTHINGLLM_API_KEY_HERE
ANYTHING_LLM_API_URL=http://localhost:3001/api/v1/workspace/smartfarm_project/chat

# Dify 配置 (可选)
DIFY_API_KEY=YOUR_DIFY_API_KEY_HERE

# 模型路径 (请替换为您的实际路径)
BGE_PATH=D:\huggingface\hub\models--BAAI--bge-m3\snapshots\xxx
YOLO_PATH=runs\detect\my_cpu_train_v16\weights\best.pt
DB_PATH=vision.db
```

### 2. 安装依赖

```bash
# 进入 core 目录
cd core

# 安装 Python 依赖
pip install -r requirements.txt

# 国内镜像加速
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 3. PyTorch 安装选项

```bash
# GPU 版本 (CUDA 11.8)
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu118

# GPU 版本 (CUDA 12.1)
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121

# CPU 版本 (无 GPU)
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
```

## 🚀 启动服务

### 方式一：分别启动各服务

```bash
# 终端 1 - 启动视觉推理服务 (端口 8004)
python vision_server.py

# 终端 2 - 启动 AI 网关服务 (端口 8001)
python ai_gateway.py

# 终端 3 - 启动超级网关 (端口 9000)
python super_gateway.py
```

### 方式二：一键启动（Windows）

创建 `start_all.bat` 文件：

```batch
@echo off
start "Vision Server" cmd /k python vision_server.py
timeout /t 5
start "AI Gateway" cmd /k python ai_gateway.py
timeout /t 5
start "Super Gateway" cmd /k python super_gateway.py
echo All services started!
```

### 方式三：一键启动（Linux/Mac）

创建 `start_all.sh` 文件：

```bash
#!/bin/bash
python vision_server.py &
sleep 5
python ai_gateway.py &
sleep 5
python super_gateway.py &
echo "All services started!"
```

## ⚠️ 重要说明

### API Key 配置

本代码已脱敏处理，您需要配置以下 API Key：

1. **Qwen API Key** - 阿里云百炼平台
   - 获取地址：https://dashscope.aliyuncs.com/
   - 配置位置：`.env` 文件中的 `QWEN_API_KEY`

2. **AnythingLLM API Key** - 本地知识库
   - 获取方式：AnythingLLM 控制台
   - 配置位置：`.env` 文件中的 `ANYTHING_LLM_API_KEY`

3. **Dify API Key** (可选)
   - 获取方式：Dify 控制台
   - 配置位置：`super_gateway.py` 中的 `Authorization` 头

### 数据库配置

1. 确保 PostgreSQL 已安装并运行
2. 创建数据库：`CREATE DATABASE agri_ai;`
3. 修改 `.env` 文件中的数据库连接信息

### 模型文件

1. **BGE-M3 模型**：首次运行会自动下载，或手动指定本地路径
2. **YOLO 模型**：需要提供训练好的 `.pt` 文件路径

## 🐛 常见问题

### 1. 端口被占用

```bash
# Windows 查看端口占用
netstat -ano | findstr :9000

# 结束进程
taskkill /PID <进程ID> /F
```

### 2. 数据库连接失败

- 检查 PostgreSQL 服务是否启动
- 检查 `.env` 文件中的数据库配置
- 检查防火墙设置

### 3. 模型加载失败

- 检查模型路径是否正确
- 检查磁盘空间是否充足
- 检查网络连接（首次下载模型时）

### 4. MQTT 连接失败

- 检查网络连接
- 确认 MQTT Broker 地址：`broker.emqx.io`
- 服务会自动重连，无需手动干预

## 📞 技术支持

2. `.env` 配置是否正确
3. 依赖是否完整安装
