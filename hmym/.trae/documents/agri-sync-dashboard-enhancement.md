# 农业智能首页交互增强计划

## 需求概述
为 AgriSyncDashboardPage.ets 增强完整交互功能，包括环境监测卡片详情、设备控制展开、作物监测详情、农事待办交互等。

## 现有代码分析

通过分析 [AgriSyncDashboardPage.ets](file:///d:/shiyan/hmym/entry/src/main/ets/pages/AgriSyncDashboardPage.ets)，现有功能：

| 模块 | 现有实现 | 需增强 |
|------|----------|--------|
| 顶部信息栏 | 通知铃铛弹窗 | 大棚选择弹窗、眼睛图标切换 |
| 环境监测 | 4个卡片显示 | 点击弹出详情弹窗、CO2时间段切换 |
| 设备控制 | Toggle开关 | 卡片点击展开详细控制页 |
| 植物生长 | 进度显示 | 点击进入详情、阶段说明弹窗 |
| 农事待办 | 按钮显示 | 按钮点击反馈、标记完成功能 |
| 底部导航 | 已注释 | 恢复并增强点击动效 |

## 实施计划

### 步骤 1: 增强顶部信息栏
- 添加 `showGreenhouseSelectModal` 状态和弹窗
- 添加 `viewMode` 状态实现眼睛图标切换（全息监测/数据列表）

### 步骤 2: 环境监测模块交互增强
- 添加环境详情弹窗组件（历史趋势、阈值设置）

### 步骤 3: 设备控制模块增强
- 添加设备详细控制弹窗组件
- 实现卡片点击展开详细控制

### 步骤 4: 植物生长模块增强
- 添加作物详情弹窗
- 添加生长阶段说明弹窗

### 步骤 5: 农事待办模块增强
- 按钮添加点击反馈动效
- 实现标记完成功能（从列表移除）

### 步骤 6: 底部导航栏恢复
- 恢复 BottomNav 组件
- 添加选中动效和脉冲动画

## 预期结果
- 所有可交互元素有点击反馈
