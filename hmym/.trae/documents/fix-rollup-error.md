# AgriSyncControlPage.ets 编译错误修复计划

## 问题诊断

**根因**：PowerShell 的 `Set-Content` 命令使用默认编码写入文件，导致 UTF-8 中文字符被损坏。

**表现**：
- 第 275 行：`Text('�?)` - 引号不闭合，字符损坏
- 第 276 行：`Text('水泵运行状�?)` - 引号不闭合
- 第 280 行：`Text(this.pumpRunning ? '运行�? : '已停�?)` - 三元表达式被损坏

## 修复方案

由于文件编码已损坏，需要**完整重写文件**，确保：
1. 使用 UTF-8 BOM 编码
2. 所有中文字符正确显示
3. 语法正确无误

## 修复步骤

1. **完整读取当前损坏的文件内容**
2. **识别所有损坏的字符串**
3. **用正确的字符串替换损坏部分**
4. **验证语法正确性**

## 预期结果

- 所有中文字符正确显示
- 无 `�` 乱码字符
- 语法解析通过
- 编译成功
