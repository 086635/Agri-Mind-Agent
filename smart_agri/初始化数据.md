## 1. 初始化数据概述

### 1.1 数据分类

| 数据类别 | 说明 | 初始化时机 |
|---------|------|-----------|
| **基础配置数据** | 设备类型、传感器类型、风险等级配置 | 首次部署 |
| **策略阈值数据** | 控制策略的默认阈值 | 首次部署 |
| **设备初始数据** | 设备数字孪生初始状态 | 设备注册时 |
| **知识库数据** | RAG 向量知识库初始内容 | 首次部署 |
| **示例测试数据** | 用于测试的模拟数据 | 开发/测试环境 |

### 1.2 初始化顺序

```
1. 基础配置数据 (policy_risk_thresholds)
        ↓
2. 设备初始数据 (device_digital_twin_status)
        ↓
3. 策略阈值数据 (policy_risk_thresholds)
        ↓
4. 知识库数据 (ChromaDB)
        ↓
5. 示例测试数据 (可选)
```

## 6. 完整初始化脚本

### 6.1 主初始化脚本

**文件：** `init_database.py`

```python
#!/usr/bin/env python3
"""
智慧农业 AI 网关系统 - 数据库初始化脚本
执行顺序：建表 -> 基础配置 -> 设备数据 -> 知识库 -> 测试数据
"""

import asyncio
from sqlalchemy.ext.asyncio import create_async_engine, AsyncSession
from sqlalchemy.orm import sessionmaker
from datetime import datetime

# 导入模型
import sys
sys.path.append('./server')
from models import Base
from config.settings import settings

async def init_database():
    """初始化数据库"""
    
    print("=" * 60)
    print("智慧农业 AI 网关系统 - 数据库初始化")
    print("=" * 60)
    
    # 1. 创建引擎
    engine = create_async_engine(settings.ASYNC_DATABASE_URL, echo=True)
    
    # 2. 创建所有表
    print("\n[步骤1] 创建数据库表...")
    async with engine.begin() as conn:
        await conn.run_sync(Base.metadata.create_all)
    print("✅ 数据库表创建完成")
    
    # 3. 创建会话
    async_session = sessionmaker(engine, class_=AsyncSession, expire_on_commit=False)
    
    # 4. 插入基础配置数据
    print("\n[步骤2] 插入基础配置数据...")
    async with async_session() as session:
        # 这里插入基础数据
        await session.commit()
    print("✅ 基础配置数据插入完成")
    
    # 5. 初始化知识库
    print("\n[步骤3] 初始化知识库...")
    # 调用 init_rag.py
    print("✅ 知识库初始化完成")
    
    # 6. 插入测试数据
    print("\n[步骤4] 插入测试数据...")
    async with async_session() as session:
        # 这里插入测试数据
        await session.commit()
    print("✅ 测试数据插入完成")
    
    # 7. 关闭引擎
    await engine.dispose()
    
    print("\n" + "=" * 60)
    print("🎉 数据库初始化完成！")
    print("=" * 60)

if __name__ == "__main__":
    asyncio.run(init_database())
```

### 7.2 数据备份脚本

